#### 🔧 [APIForge – API Workspace & Testing Platform](https://github.com/mubashir-hsn/APIForge)
Build, test, organize, and debug APIs from one powerful workspace. A full-stack app for creating and executing saved API requests inside shared workspaces.
 
- **Frontend:** React (Vite + Tailwind + Zustand)
- **Backend:** FastAPI (JWT auth + SQLAlchemy)
**Key Features:**
- JWT authentication (Register/Login) with protected routes via `Authorization: Bearer <token>`
- Workspaces — create workspaces, add members (owner-only), list user workspaces
- Collections scoped to a workspace
- Save, organize, and execute API requests (method, URL, headers, query params, body)
- Request execution history stored and retrievable
- Environment variables scoped per workspace
**Tech:** `React` `Vite` `Tailwind CSS` `Zustand` `FastAPI` `SQLAlchemy` `JWT`
